## Overview

ABYSS layers a wavetable oscillator with a granular cloud engine, routing both through a modular effects chain, to produce enormous, slowly breathing ambient textures and cinematic soundscapes.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Dawesome ABYSS** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Wavetable Engine** | 128-frame wavetable scanner with continuous morph and phase warp |
| **Granular Cloud** | Stochastic grain engine with spray, density, and position scatter |
| **Modular FX** | Drag-and-drop effects chain with reverb, delay, filter, and chorus |
| **Macro Morphing** | Single macro morphs wavetable position and granular density together |
